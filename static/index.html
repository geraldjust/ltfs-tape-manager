How verification works

Each restored file is SHA-256 hashed as it is read from tape, then its destination copy is hashed and compared. The tape is not read a second time, avoiding unnecessary repositioning.

A restore may take a long time on tape. Do not interrupt the drive. Verify the output before deleting any other copies.

Format tape

Read the inserted cartridge's status before formatting. A blank or unformatted cartridge does not need to mount.

Press Read tape info to check cartridge readiness.

New LTFS volume name

Optional tape serial / barcode (6 letters or digits)

DANGER: Formatting permanently destroys existing tape data. Only test with your known blank cartridge. No automatic formatting or retries.

Tape formatting may take approximately 2–10 minutes. Do not eject the cartridge or interrupt the operation while formatting is in progress.

The format operation runs in the background. Status refreshes every five seconds and independent drive inquiries are paused during formatting. After success the tape is mounted read-only for verification.

Uncompressed TAR packaging groups small files from the same immediate folder. Archives are written directly to tape without HDD staging.

Default unchecked: read source once while writing, then independently verify the tape. Checked: also read the original source a second time after read-only remount; this takes longer, especially on HDDs.

Write performs a read-write mount, copies new files, commits the LTFS index by clean unmount, remounts read-only and checks SHA-256. Do not interrupt the drive. Existing tape files are never overwritten.
